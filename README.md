# 🌐 Proximamente

Frontend simple y moderno desarrollado en **Angular** con **TailwindCSS**, que permite a los usuarios registrarse con su correo electrónico para recibir novedades sobre el lanzamiento de mi portfolio y/o futuros proyectos.

Consume la API [`proximamente-api`](https://github.com/FabrizioFerroni/proximamente-api), desarrollada en Node.js con Express, TypeScript y MySQL.

---

## ✨ Funcionalidades

- ✅ Página responsive con formulario de suscripción.
- ✅ Validación de email en tiempo real.
- ✅ Conexión con backend vía HTTP.
- ✅ Feedback visual de éxito o error.
- ✅ Estilos modernos y minimalistas con TailwindCSS.

---

## 🛠️ Tecnologías

- [Angular](https://angular.io/) (v20+)
- [TailwindCSS](https://tailwindcss.com/)
- RxJS
- Angular Forms
- Angular CLI
